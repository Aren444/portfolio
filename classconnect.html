ClassConnect

A VR classroom concept supported by interactive prototyping and usability evaluation.

Read Usability Analysis

Project Overview

ClassConnect is a concept for an immersive virtual reality classroom that helps teachers and parents make remote lessons more engaging. The proposal explored student and educator needs, AI-supported peer avatars, accessibility options, and teacher-controlled lessons. I developed personas, task flows, sketches, wireframes, a storyboard, and an interactive prototype. I also evaluated the prototype using usability heuristics and observations from a user session. That review revealed opportunities to improve navigation cues, error feedback, visual consistency, and onboarding. This work demonstrates a user-centered process that moves from researching a problem to testing a proposed interactive learning experience with students in different settings.

Design & Development

I researched comparable VR education experiences, mapped classroom tasks, built a small interactive prototype, and tested its usability. The evaluation describes improvements I would make to feedback, controls, and navigation; it does not claim those revisions were already implemented.

CMST 308 – User Interface Design · 2025 · UI wireframes, interactive prototype, heuristic evaluation · Independent project, all work by Aren Bird
